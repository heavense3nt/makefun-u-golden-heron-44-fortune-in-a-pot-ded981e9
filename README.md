A tiny deterministic program that writes one kind, funny fortune for a houseplant — a single line of at most 120 characters, unmistakably about the plant on the windowsill — to `entry.txt`. The fortune: "The leaves whisper it first: sunshine, a warm sill, and a human who finally waters you on time this week."

## Run it

```sh
node main.ts
```
